# Secure Azure Infrastructure with Terraform

Terraform modules and examples for deploying secure Azure infrastructure: private endpoints, resource-scoped identity permissions (managed identities and RBAC), Azure Key Vault integration, encryption controls, and diagnostic logging.

> 🚧 Work in progress — modules and examples are being built out. Check back soon.

## Planned contents

- `modules/` — reusable Terraform modules (networking with private endpoints, Key Vault, RBAC/identity, diagnostic settings)
- `examples/` — end-to-end reference deployment
- `docs/` — architecture notes and security control mappings
